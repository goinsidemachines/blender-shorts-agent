# Security

## Reporting a problem

Please report security problems privately through GitHub: on this repository, open **Security → Report a
vulnerability**. Don't open a public issue for them.

You'll get a reply within a week. Once a fix is released, the report is credited to you unless you'd rather not.

## What counts

Anything that lets the plugin do something the user didn't approve: download or run code without the approval
list, send data anywhere the README's "What it runs and connects to" section doesn't name, read or leak an API key,
or write outside the plugin's settings folder and the user's workspace.

## Supported versions

Only the latest release gets fixes.
